# Files this pack owns outright.
#
# An instance is merged from the pack three ways, and a file that matches
# neither the pack's old copy nor its new one is taken for the player's work
# and left alone. That is right for a setting somebody tuned by hand and wrong
# for a file the game rewrites on its own - such a file looks edited from the
# first launch, so nothing shipped here could ever reach it again.
#
# Everything listed below is written over instead. What was there is copied
# into the instance's conflicts folder first, as name.user-file, so a change
# somebody did mean can be put back.

# NeoForge normalises this one at every start. A dependency override left in it
# named a mod this pack no longer has, and the game answered with a red warning
# screen on every launch - the corrected file could not reach the instance
# because the loader's own rewrite made it look like somebody's edit.
config/fml.toml

# All The Tweaks rewrites this file on start. Keep current branding/schema
# and the portable pack setting that disables Discord Rich Presence.
config/allthetweaks-common.toml

# The same answer to a second asker. This pack's own update check, in
# kubejs/startup_scripts/update_checker.js, reads its version out of Better
# Compatibility Checker - whose config ships "CHANGE_ME", a version with no
# numbers in it, so every release on CurseForge counted as newer. BCC rewrites
# this file on start too, so the real name and version reach an instance that
# already exists only by being claimed here.
config/bcc-common.toml

# FTB Quests and its language splitter rewrite the pack's quest definitions
# and merge split translations during play. Updates must replace those files,
# including upstream removals, while keeping the previous copies in conflicts.
# Completed tasks, claimed rewards and team progress live inside each world
# under ftbquests/ and are not part of this rule.
config/ftbquests/quests/**
