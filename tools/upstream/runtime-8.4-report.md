# Нативная проверка ATM10 8.4

Клиент Minecraft 1.21.1 / NeoForge 21.1.265 дошёл до настоящего главного меню:
три последовательных замера на render executor, без overlay, мира, игрока и
встроенного сервера. Штатный `Minecraft.stop` завершил процесс с кодом 0.
Все 490 авторских JAR повторно проверены по SHA256 и размеру, затем связаны с
точными загрузками авторского manifest либо с overrides закреплённого архива.
Единственный дополнительный мод — общий транспорт E4Steam лаунчера.

| Нативный замер | Результат |
| --- | --- |
| NeoForge ModList | 534 компонента |
| KeyMapping.ALL / Options.keyMappings | 574 / 567 |
| GPU | Intel Arc B390, предел текстур 16 384 |
| AdvancedAE | Исходный 1.6.12, SHA256 `a01d9718667ac13899013e91c5b0b7708b9b9db1da9b8e380772dde54bbe8f41` |
| CC:Tweaked, выбранный NeoForge | 1.120.2, SHA256 `e8651fe24b384e925e563c9ad077644744474e2e7c0adb8e6d5b4757598dce9f` |
| Завершение | Штатное, exit 0 |

AdvancedAE не заменялся производным JAR, глобального переписывания его меню в
лаунчере нет. Для проверенной инициализации исправление не потребовалось.
Взаимодействие с меню AdvancedAE и его поведение в мире этим не проверены.

В авторском составе обнаруживаются оба CC:Tweaked: 1.113.1 и 1.120.2.
Фактический ModList выбрал 1.120.2; native discovery относит вложенные Cobalt
0.9.9 и jzlib 1.1.3 к этому же JAR. Подготовка не удаляла и не отключала старый
авторский файл.

В прогоне использовались настоящие общие службы установки и композиции JVM
из точного опубликованного исходного кода лаунчера 420. Сам тестовый managed
binary собран независимо в Debug; это не заявление о побайтовом совпадении с
публичным EXE. Измерения делал отдельный наблюдатель без трансформаций классов,
физического ввода и изменения клавиш. Только в техническом экземпляре после
первого экрана доступности задано `onboardAccessibility:false`; исходники
сборки и личные настройки не менялись.

размеры и SHA256 находятся в [runtime-8.4-report.json](runtime-8.4-report.json).

Ошибки не подавлялись, моды и эффекты не отключались. Их происхождение
сопоставлено с точными авторскими байтами, а не объявлено унаследованным только
на основании успешного главного меню. Отдельного полного author-only baseline
для ATM10 8.4 не было.

Этот результат подтверждает загрузку до главного меню и инвентарь нативных
регистраций. Новый мир, старый личный мир, LAN/Steam-соединение, два клиента,
способности и визуальная оценка не проверялись. Личные миры не читались и не
копировались, перенос без потерь не обещан. Необработанные логи, личные пути,
идентификаторы игрока и параметры профиля в этот отчёт не включены.
